# Beginner Code Examples

Short examples for people learning to code. Each example focuses on one idea.

## Python
Run with `python filename.py`.
- `hello.py` — print a message
- `temperature.py` — convert Celsius to Fahrenheit
- `even_or_odd.py` — use the modulo operator

## JavaScript
Open `javascript/index.html` in a browser.
- `javascript/script.js` — button click and DOM update

## Learning path
1. Change the example values.
2. Predict what the program will display.
3. Run it and compare.
4. Add one feature of your own.

Beginner-friendly improvements and translations are welcome.
